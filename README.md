# Silence Computer Use

**让 agent 操作电脑，让你继续使用电脑。**

传统 computer use 让 agent 通过读屏、点击、输入和快捷键完成 GUI 任务。如果它直接操作你正在使用的桌面，你就得暂时让出鼠标和键盘：你的一次点击可能改变 agent 的输入目标，agent 的一次窗口切换也可能打断你的工作。

`silence-computer-use` 将这些操作放进独立的 Windows 虚拟桌面／影子会话。你继续使用当前桌面，agent 在自己的会话里启动应用、观察窗口并完成操作。日常键鼠输入由虚拟会话内的 agent 执行，不发送到你正在使用的桌面。

## 与传统 computer use 有什么不同？

这里的「传统 computer use」指直接控制用户当前桌面的方式。

| 对比项 | 传统 computer use | Silence Computer Use |
| --- | --- | --- |
| 操作空间 | 用户正在使用的桌面 | 运行时创建的独立 Windows 影子会话 |
| 鼠标与键盘 | 与用户共用当前桌面的输入，容易互相干扰 | 在虚拟会话内发送输入，用户继续操作自己的桌面 |
| 窗口与焦点 | 打开、激活窗口可能打断用户 | 应用在虚拟会话里打开，焦点变化留在该会话 |
| 观察对象 | 当前桌面或其窗口 | 虚拟会话内的窗口、UIA 文本和截图 |
| 工作方式 | 用户通常需要暂时让出电脑 | 用户与 agent 可以在不同会话中同时工作 |
| 结果交付 | 保存到本机 | 同样保存到本机，用户可直接读取成果 |

它保留了 computer use 对真实 GUI 的操作能力，并将操作空间移到独立会话。对用户而言，主要变化是：**agent 执行桌面任务时，不再占用你当前桌面的鼠标、键盘和窗口焦点。**

## 它能做什么？

- **启动和发现应用**：枚举可用应用、启动程序、列出会话内的窗口。
- **观察界面**：读取 Windows UI Automation（UIA）控件树和文本，获取窗口截图；必要时获取整个虚拟桌面的画面。
- **操作真实 GUI**：点击、输入、快捷键、滚动、拖拽，以及按控件索引设置值或执行辅助动作。
- **连续执行任务**：通过单次命令或 NDJSON 请求流，完成多步观察、操作和验证。
- **交付本机文件**：把成果保存到指定的本机路径，结束虚拟会话后仍可使用已保存的文件。

适合需要桌面 GUI、步骤较多，又不希望中断当前工作的任务，例如在应用中填写表单、调整界面设置、整理并导出文件。具体应用能否正常启动、读屏和操作，需要在实际会话中验证。

## 如何做到不抢占前台操作？

技能由三层组成：

1. **`vdcu` 创建并管理独立会话**，提供自己的桌面和输入环境。
2. **Kimi CU agent 在该会话内运行**，负责窗口观察、UIA 读屏、截图和键鼠操作。
3. **Python 脚本通过专用命名管道发送请求**，将任务交给会话内的 agent。

```text
用户 → 当前 Windows 桌面 → 继续自己的工作

agent → vd_cu.py → 专用命名管道 → 会话内的 Kimi CU
                                      ↓
                              独立虚拟桌面中的应用
                                      ↓
                              保存成果到本机路径
```

默认管道为 `\\.\pipe\kimi-cu-win-vd`。会话内的 agent 自己执行输入，因此操作不需要切换或接管用户桌面。这里的「虚拟桌面」指运行时创建的独立 Windows 影子会话。

## 快速开始

需要 Windows 和 Python 3.10+。

将本项目的 `skills/silence-computer-use/` 整个文件夹复制到项目的技能目录中，按你使用的 agent 选择以下一种位置：

```text
.agents/skills/silence-computer-use/
```

或者：

```text
.claude/skills/silence-computer-use/
```

安装后的目录结构如下（以 `.agents` 为例）：

```text
你的项目/
└── .agents/
    └── skills/
        └── silence-computer-use/
            ├── SKILL.md
            ├── scripts/
            ├── references/
            └── runtime/
```

请保留完整技能目录，包括 `runtime/cu.exe` 和 `runtime/vdcu/`，不要只复制 `SKILL.md`。

安装后，在该项目中启动 agent，并直接描述任务：

> 请使用 silence-computer-use，在虚拟桌面中完成指定应用的操作，将成果保存到我指定的本机路径。完成后验证结果并退出会话。

agent 会按照技能说明检查运行环境、创建或复用虚拟会话，并在会话内执行任务。
